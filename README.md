# 이지양 · AI 서비스 · LLM 개발자 포트폴리오

정적 HTML / CSS / JavaScript 포트폴리오입니다. 별도 빌드나 유료 서비스 없이 GitHub Pages에 배포할 수 있습니다.

## 페이지와 구성

- `index.html`: 소개, 대표 프로젝트, 역량, 추가 프로젝트와 연락처
- `#/projects/super-marimo`, `#/projects/heatgrid-agent`, `#/projects/focus-on-class`, `#/projects/smart-light`: 새로고침 가능한 프로젝트 상세 주소
- `assets/styles.css`: DESIGN.md의 공통 토큰과 반응형 레이아웃
- `assets/projects.js`: 프로젝트 내용, 역할의 출처와 검증 한계
- `assets/app.js`: 해시 탐색, 브라우저 뒤로 가기, 데모 링크 적용
- `assets/demo-links.json`: 공개 Vercel 데모 URL 설정. 기본 링크도 동일한 공개 주소를 사용하므로 설정 요청이 실패해도 체험 페이지로 이동할 수 있습니다.
- `components.html`: 공통 요소와 초점·비활성·메시지 상태 확인용 페이지

프로필 사진은 본인 제공 원본을 생성형 편집 없이 정사각 크롭하고 240/480/720 해상도로 저장했습니다. 원본은 저장소에 포함하지 않습니다.

웹 데모는 샘플 기반 체험이며 실제 장치, 모델 추론이나 현장 제어와 구분합니다. 개인 기여·학력은 본인 제공 자료, 기술 동작은 공개 저장소 및 감사 결과를 기준으로 기술했습니다. 검증 자료 간 불일치가 있는 성능 수치는 표지에서 제외했습니다.

## 로컬 확인

정적 HTTP 서버에서 이 폴더를 열어 확인합니다. 파일 URL은 브라우저 보안 정책으로 JSON 설정을 불러오지 못할 수 있으나 기본 데모 링크는 유지됩니다. 모바일 375px, 태블릿 768px, 데스크톱 1280px에서 상세 이동, 뒤로 가기, 연락처와 초점 표시를 확인합니다.
